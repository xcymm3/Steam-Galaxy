# Tests boundary

单元测试、匿名 fixtures 与后续端到端测试分别放在此目录下的对应子目录中。`fixtures/steam/` 仅使用虚构昵称、测试域名与合成标识，不得加入真实玩家的完整响应。

Steam 测试覆盖身份解析、官方 API 边界、响应标准化、OpenID 状态校验、缓存策略、密钥隔离与错误映射。`fixtures/report.ts` 提供普通玩家、千小时单推、500+ 库存、空库存、纯零时长和超长中文昵称等合成样本。

星系测试覆盖确定性排序、前 100 个独立天体、长尾档案聚合、零时长信号、物理体积比例、场景轨道与镜头焦点。工作台测试覆盖标签页会话恢复、缺失会话降级、游戏星系入口、星体详情面板与按需读取 Steam 商店元数据的成功、失败和重试路径。

jsdom 用于组件语义与交互契约；Three.js 的真实渲染、拖动、缩放、点选和不同视口布局必须在浏览器中以匿名合成报告做视觉验收，不能由 jsdom 替代。
