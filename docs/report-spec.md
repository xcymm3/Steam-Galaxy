# 报告规格

- 状态：Accepted for MVP
- 版本：0.1
- 日期：2026-07-21

## 1. 报告契约

一份报告是玩家当前公开 Steam 数据形成的生涯快照，不是逐年历史档案。

报告必须满足：

- 总共 10 页。
- 用户手动进入下一页，不自动播放。
- 正常阅读时长控制在两分钟内。
- 每页只表达一个主要结论。
- 所有数字来自 Steam 数据或明确的派生计算。
- 无法验证的购买动机、夜间游玩和历史口味变化不进入报告。
- 最后一页生成一张分享海报。

## 2. 概念数据模型

### Player

| 字段         | 必需 | 用途                            |
| ------------ | ---- | ------------------------------- |
| SteamID64    | 是   | 请求 Steam 数据，不在海报上展示 |
| 昵称         | 是   | 报告和海报署名                  |
| 头像         | 否   | 报告首屏和海报；失败时降级      |
| 资料 URL     | 否   | 错误处理和用户确认              |
| 账号创建时间 | 否   | 计算 Steam 年龄；缺失时不展示   |

### Owned Game

| 字段         | 必需 | 用途                         |
| ------------ | ---- | ---------------------------- |
| AppID        | 是   | 游戏唯一标识                 |
| 名称         | 是   | 文案和列表                   |
| 累计游玩分钟 | 是   | 全部核心分析                 |
| 图标标识     | 否   | 星图详情、Top 游戏和海报     |
| 最近游玩时间 | 否   | 仅作辅助信息，不用于历史叙事 |

### Report Metrics

| 指标         | 计算方式                         |
| ------------ | -------------------------------- |
| 游戏总数     | 当前返回的有效游戏条目数         |
| 玩过的游戏数 | 累计游玩分钟大于 0 的条目数      |
| 未游玩游戏数 | 累计游玩分钟等于 0 的条目数      |
| 低时长游戏数 | 大于 0 且小于 120 分钟的条目数   |
| 累计游玩时长 | 所有有效条目的分钟数之和         |
| 触达比例     | 玩过的游戏数 ÷ 游戏总数          |
| Top 1 占比   | 第一名分钟数 ÷ 累计分钟数        |
| Top 3 占比   | 前三名分钟数之和 ÷ 累计分钟数    |
| 低时长比例   | 低时长游戏数 ÷ 玩过的游戏数      |
| Steam 年龄   | 当前日期与账号创建时间的完整年差 |

所有除法在分母为 0 时返回 `null`，不得显示 `NaN`、`Infinity` 或误导性的 0%。

## 3. 十页故事顺序

| 页  | 页面职责 | 主结论                 | 主要视觉                   | 降级策略                  |
| --- | -------- | ---------------------- | -------------------------- | ------------------------- |
| 1   | 身份确认 | “已连接到你的游戏宇宙” | 头像、昵称、账号年龄       | 无年龄时只显示昵称        |
| 2   | 时间规模 | 累计投入了多少小时     | 巨型数字、微弱恒星光       | 低时长仍显示真实数字      |
| 3   | 库存规模 | 拥有多少、真正玩过多少 | 两组数字与触达比例         | 零库存进入专门错误状态    |
| 4   | 引力中心 | 哪款游戏游玩最久       | 单颗主星、名称、时长和占比 | 无图标时使用文字星体      |
| 5   | 五颗主星 | Top 5 如何分配时间     | 小型行星系统               | 少于 5 款时按实际数量展示 |
| 6   | 完整星图 | 所有游戏按时长组成宇宙 | 可交互星图                 | 低性能设备显示静态星图    |
| 7   | 专注度   | 单推还是雨露均沾       | Top 3 占比与玩过数量       | 总时长为 0 时跳过结论     |
| 8   | 落灰区域 | 哪些游戏几乎没怎么玩   | 未玩/低时长数量和少量名称  | 不使用购买动机文案        |
| 9   | 玩家称号 | 规则引擎最终判断       | 大标题、称号解释           | 数据不足时使用新玩家称号  |
| 10  | 分享     | 带走这份游戏宇宙       | 海报预览、下载、系统分享   | 海报失败时支持重试        |

## 4. 页面交互契约

- 顶部显示 10 段进度，不显示复杂导航。
- 底部主按钮文案为“下一页”；最后一页改为“生成分享图”。
- 第二页之后提供低视觉权重的“上一页”。
- 桌面端支持左右方向键。
- 移动端可以支持左右滑动，但按钮始终保留。
- 用户操作后才翻页，不定时自动前进。
- 页面切换后将焦点移动到新页面标题，方便键盘和读屏用户。
- `prefers-reduced-motion` 下只使用短暂透明度切换。

## 5. 星图规格

### 数据映射

- 星球面积与累计游玩分钟成正比。
- 半径采用游玩分钟平方根缩放，并设置最小和最大视觉半径。
- 第一名位于视觉中心。
- Top 5 使用唯一的暖色强调。
- 其他已玩游戏使用中性冷白色。
- 0 小时游戏不参与主星球半径竞争，表现为外围尘埃。
- 不使用颜色表示游戏类型，因为 MVP 没有可靠类型数据。

### 数量控制

- 1～100 款：每款游戏可成为独立节点。
- 超过 100 款：保留时长最高的 100 款，其余聚合为“远端星云”。
- 纯 0 小时库存：不生成误导性的大小排序，改为展示未点亮宇宙状态。

### 确定性

相同的 SteamID、AppID 集合和时长必须产生相同布局。排序以游玩分钟降序、AppID 升序作为稳定次序，禁止使用未设种子的随机数。

### 无障碍

Canvas 之外提供一个与当前选中星球同步的文本区域。星图不是唯一的信息载体，Top 游戏和关键数字必须同时以文本出现。

## 6. 称号规则

MVP 每次只生成一个主称号。初始规则按以下优先级匹配，阈值在真实样本测试后允许调整：

| 优先级 | 称号             | 初始条件                                | 解释模板                                   |
| ------ | ---------------- | --------------------------------------- | ------------------------------------------ |
| 100    | 时间管理失踪人口 | 累计时长 ≥ 5000 小时                    | “你在 Steam 里留下了 {hours} 小时。”       |
| 90     | 千小时钉子户     | Top 1 时长 ≥ 1000 小时                  | “光是《{game}》就留住了你 {hours} 小时。”  |
| 80     | 赛博单推人       | Top 1 占比 ≥ 55%，且累计时长 ≥ 300 小时 | “你超过一半的时间都交给了《{game}》。”     |
| 70     | 库存守门员       | 游戏总数 ≥ 200，且未玩比例 ≥ 60%        | “你守护着 {count} 个还没真正打开的世界。”  |
| 60     | 两小时巡逻员     | 玩过 ≥ 30 款，且低时长比例 ≥ 65%        | “你的足迹遍布库存，但很多只停留了两小时。” |
| 50     | 雨露均沾型宇航员 | 玩过 ≥ 80 款，且 Top 1 占比 < 20%       | “没有一颗星球能独占你的全部注意力。”       |
| 10     | 宇宙刚刚点火     | 数据量不足以匹配其他规则                | “你的游戏宇宙还在继续扩张。”               |

规则引擎要求：

- 条件与文案分离。
- 同时命中时只选最高优先级。
- 所有插值数据必须来自报告指标。
- 禁止按昵称、头像或单个游戏名称推断人格。
- 不生成医学、财务或成瘾诊断式称号。

## 7. 分享海报规格

- 尺寸：1080 × 1440。
- 格式：PNG。
- 方向：竖版。
- 二维码：固定指向项目首页，不携带 SteamID。
- 默认允许展示头像、昵称、Top 游戏和累计时长。

海报固定包含：

1. `WHERE DID THE HOURS GO?` 品牌标题。
2. 玩家头像与昵称。
3. 主称号。
4. 累计游玩小时。
5. 游戏总数与玩过数量。
6. 最常玩的游戏及其时长。
7. Top 3 小型星系。
8. 简化星图。
9. 首页二维码与邀请文案。

头像、游戏图标或外部字体加载失败时，海报仍必须能够生成。

## 8. 文案诚信规则

允许：

- “你累计玩了 3421 小时。”
- “《某游戏》占据了你 43% 的已记录时长。”
- “这些游戏的累计时长不足两小时。”

禁止：

- “这款游戏吞掉了你最多的夜晚。”
- “你在 2021 年从 FPS 转向 RPG。”
- “这些游戏买下时很期待，后来再没打开。”
- “你和朋友共同经历了这段游戏时期。”

## 9. 必测数据样本

- 无效 SteamID。
- 私密游戏详情。
- 0 款游戏。
- 只有 1 款游戏。
- 少于 5 款游戏。
- 500 款以上库存。
- 全部游戏为 0 小时。
- 单款游戏超过 10000 小时。
- 极长中文、英文和 Emoji 昵称。
- 头像或游戏图标无法加载。
- 缺少账号创建时间。
- 多个称号规则同时命中。
